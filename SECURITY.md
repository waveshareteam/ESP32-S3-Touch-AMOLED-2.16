# Security Policy

Please do not report security vulnerabilities through public issues.

For suspected vulnerabilities, contact Waveshare through the official support
channel and include:

- Affected product or repository
- A concise description of the issue
- Reproduction steps or proof of concept when safe to share
- Potential impact
- Suggested mitigation if known

Avoid sharing secrets, private keys, personal data, or sensitive device
information in public repository text.

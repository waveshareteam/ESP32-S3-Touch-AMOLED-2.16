# Immersive block example

[简体中文](README_ZH.md) · [Home](../../../README.md)

This first-party ESP-IDF project demonstrates an LVGL block interaction using
QMI8658 motion input. It is discovered as `04_Immersive_block` and is built by
the selected ESP-IDF matrix with `v5.5.5` and `v6.0.2`.

Use the repository-level [CI guide](../../../docs/ci.md) for dispatch and matrix
selection. This page does not change board pins, dependencies, or factory firmware.
